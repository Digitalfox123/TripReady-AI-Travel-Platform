**TripReady** is an all-in-one, intelligent travel planning and discovery platform designed to deliver personalized day-by-day itineraries, real-time country intelligence, interactive media guides, and specialized religious tourism experiences.

---

## 🌟 Key Highlights & Features

- 🧠 **AI Trip Planner**: Tailor-made day-by-day itineraries generated dynamically according to trip duration, traveler style, budget tier, and party size.
- 🏛️ **Country & City Explorer**: Deep dive into 200+ global destinations featuring visa requirements, real-time safety indices, climate timelines, transport routes, and cultural etiquette tips.
- 🖼️ **Wikipedia REST API Integration**: Free, keyless, real-time image resolution fetching authentic high-resolution landmark and city photos worldwide.
- 🎥 **YouTube Travel Experience**: Seamless integration of 4K walking tours, cinematic documentaries, and travel guides using YouTube Data API v3.
- 🕋 **Umrah & Religious Tourism Hub**: Step-by-step Umrah guide, interactive spiritual planning, and curated historical Ziyarat sights across Makkah and Madinah.
- 💰 **Smart Budget & Expense Estimator**: High-fidelity cost breakdown (Budget, Mid-Range, Luxury) paired with live multi-currency conversion.
- ⚡ **Offline-First Instant Save**: High-speed trip saving (<5ms latency) to local storage with non-blocking cloud synchronization via Supabase.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Digitalfox123/TripReady-AI-Travel-Platform.git
   cd TripReady-AI-Travel-Platform
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
