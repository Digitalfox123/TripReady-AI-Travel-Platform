# Metadata & SEO Guidelines

Ensure all pages are fully optimized with complete search and social preview metadata.

## Rules
1. **Title & Meta Description**: Every page must have a descriptive, unique title and target meta description.
2. **Open Graph Metadata**: Include `og:title`, `og:description`, `og:image`, `og:url`, and `og:type` tags.
3. **Structured Schema**: Implement JSON-LD schema (FAQPage, BreadcrumbList, LocalBusiness) to assist search spiders.
4. **Canonical URLs**: Declare canonical links to avoid duplicate content penalties.
